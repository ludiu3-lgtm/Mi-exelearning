9. GUÍA DIDÁCTICA

Orientaciones para aplicar este proyecto en el aula de forma eficaz e inclusiva

Este proyecto está diseñado para ser aplicado en el aula de forma flexible y adaptada a las necesidades del alumnado.

Se recomienda:

  • Utilizar apoyos visuales y ejemplos: Uso de pictograma
  • Diferentes niveles de dificultad
  • Posibilidad de trabajo en pareja
  • Adaptar las actividades a los distintos ritmos de aprendizaje
  • Fomentar el trabajo cooperativo
  • Aplicar principios del Diseño Universal para el Aprendizaje (DUA)
  • La evaluación se realizará de forma continua, teniendo en cuenta tanto el proceso como el producto final.
